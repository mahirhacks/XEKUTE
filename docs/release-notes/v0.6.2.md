# XEKUTE 0.6.2

This patch release hardens long-running assessments and fixes multiple bugs
in context recovery, project switching, artifact persistence, file access,
identity storage, and proxy lifecycle handling.

## Agent context and interruption recovery

- Preserve steering across summarization, interruption, retry, continuation,
  and restart. Prevent stale model results and queued tool actions from
  running against a superseded task.
- Recover a matching checkpoint and active conversation ledger after partial
  writes or corruption. Keep the previous valid checkpoint available and
  avoid replaying content already committed to a checkpoint.
- Fix memory identity hashing for shared object references without accepting
  actual cycles.

## Project switching and save ordering

- Ignore stale responses for project loads, file trees, directory maps,
  profiles, identities, guidance, and WebClone content.
- Keep each manual save and autosave attached to its original project and
  form snapshot, including A-to-B-to-A switches and saves queued across
  multiple projects.
- Stop superseded credential writes and profile refreshes. Report save
  failures without unhandled promise rejections.

## Persistence and file access

- Make hypothesis, checklist, evidence, and project-index writes recoverable
  through a durable transaction journal.
- Preserve committed IDs and state after journal-cleanup failures. Refuse
  discard requests for durable transactions, and roll back transaction-owned
  changes when recovery encounters a conflicting edit.
- Reject symlink and junction escapes across workspace mutations, WebClone,
  traffic storage, artifact files, and transaction directories.
- Use validated file descriptors for traffic reads, appends, and deletions
  so replacing a log with a symlink during access cannot redirect the operation.
- Recover missing or corrupt project profiles from valid backups, and keep
  deleted identities from being recreated by an in-flight credential save.
- Honor exclusions without requiring a positive allowlist, and prevent late
  traffic capture from recreating a removed project.

## Proxy, scope, and process hardening

- Serialize proxy reconfiguration so the latest project request wins.
- Cancel stopped listener startups and prevent old listeners from reviving.
- Correct IPv6 proxy address formatting for browser launches.
- Block private IPv4-mapped IPv6 targets and IPv6 documentation ranges at
  the public-target scope boundary.
- Finish terminating detached POSIX process groups after their root exits.

## Packaging

Remove the unused bundled BGE model, transformer dependency, and ONNX runtime.
The package verifier checks that the retired runtime assets do not ship.

The full fix list is in the
[0.6.2 changelog](https://github.com/mahirhacks/XEKUTE/blob/v0.6.2/CHANGELOG.md).

## Validation

The hardening pass passed 1,435 tests with no failures and one
platform-specific skip. It also passed the production architecture check,
native-module check, UI build, all eight browser verification workflows, and
Windows package inspection. The release workflow repeats the production
checks, test suite, installer build, and package verification for this tag.

## Download and update

- Install `XEKUTESetup.exe`, or use the in-app updater.
- `latest.yml` and the blockmap support automatic updates.
- `SHA256SUMS.txt` contains the published artifact checksums.
- `xekute-sbom.cdx.json` contains the dependency inventory.

XEKUTE remains an alpha product. Two low-severity Mermaid/KaTeX dependency
advisories remain; the automated fix requires a breaking major upgrade.
Canonical artifact Markdown follows a single-writer contract, with a narrow
external-writer race remaining between the final hash check and rename.
