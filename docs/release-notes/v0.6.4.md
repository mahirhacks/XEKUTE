# XEKUTE 0.6.4

This release refreshes the update prompt and the empty project panel to match
the rest of XEKUTE, and fixes the File menu and lost keystrokes after creating
a file.

## Interface

- The update prompt has a quieter design: 6px corners, a hairline border, and
  gray buttons. It names the version on offer. While downloading, a flat
  progress bar sits under the title and a close button hides the prompt. When
  the update finishes, a check icon confirms it.
- The No Project Open panel and the assessment setup panel use gray buttons
  with proper spacing between icon and label.

## Fixes

- File > Create New File, Create New Folder, Save File and Close Editor are
  disabled until a project or an editor is open. Before, they showed an alert
  or did nothing.
- Typing straight into a newly created file no longer loses keystrokes. A
  background explorer refresh, such as the one that follows a file change, no
  longer pulls keyboard focus out of the editor or chat.
