# Authority profiles

XEKUTE has three active execution-interaction profiles:

- Ask for Approval requests operator approval for covered tool operations.
- Approve for Me continues low-risk, in-scope operations automatically and
  escalates configured exceptions, irreversible operations, and high risk.
- Full Authorization performs no interactive approval but retains every other
  authority and lifecycle control.

Profiles govern interaction policy only. They never expand the active mode's
tool surface, assessment scope, identity, plan-bound action set, or resource
limits.
