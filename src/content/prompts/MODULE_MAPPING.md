# Prompt module classification (Stage 1)

This file is the checked-in mapping required by T1.6/T1.7. It records how every
`src/prompts/**` module is classified during Stage 1 of the production-layer
restructure.

Legend:

- **prose** — human-editable Markdown prose; generated into `src/content/build/`.
- **logic** — deterministic JavaScript (regexes, state machines, validators,
  redaction, enforcement); retained as hand-authored `.js`, relocated in Stage 5.
- **mixed** — contains both prose and deterministic logic; only split when an
  exact export snapshot proves equivalence; otherwise retained as a documented
  compatibility module.
- **compat** — compatibility-only module whose home/consumers have not yet moved;
  retains the same public exports until its Stage 5 destination is implemented.

## Mixed / compatibility (kept at current path until Stage 5)

- `src/prompts/instructs/initial_prompt.js` — mixed; contains hand-authored
  prose and deterministic authority/context rules. It is NOT generated by the
  builder. Keep at the current path with its existing exports
  (`XekuteInitialPrompts`, `runtimeAuthority`, etc.) until Stage 5 separates
  prose from deterministic policy.
- `src/prompts/instructs/triage_prompt.js` — mixed; hand-authored prose plus
  helper logic (`actionRetry`, `postToolSummary`, `planGrounding`,
  `verification`, `failedVerification`, `VERIFIER_SYSTEM_PROMPT`). Keep at the current path until Stage 5.
- `src/prompts/skills/context-router.js` — compat; browser global
  `XekuteContextRouter` and Node export. Kept in place to preserve renderer
  script-load order until Stage 7 updates HTML paths.
- `src/prompts/skills/cyber-library.js` — compat; VAPT cyber guidance consumed
  by `controller.js`. Kept at current path until Stage 5.
- `src/prompts/skills/mode-skills.js` — compat; aggregates the four generated
  mode-skill modules and `operating-mode-rules`. Kept at current path until
  Stage 5, when it can consume `content/build` mode modules directly.
- `src/prompts/skills/vapt-skill-library.js` — compat; aggregates generated
  library modules. Kept at current path until Stage 5, when it can consume
  `content/build` libraries directly.
- `src/prompts/skills/modes/*.js`, `src/prompts/skills/libraries/*.js` — old
  generated locations retained only as compatibility output while
  `mode-skills.js` and `vapt-skill-library.js` still require them. The canonical
  generated output is now `src/content/build/`.

## Consumers

- `src/agent/instructions/prompt-compiler.js` → moved to
  `src/application/prompt/prompt-compiler.js`; Node uses
  `src/content/content-loader.js` (`systemPrompt()`); browser uses the preloaded
  `XekuteSystemPrompt` global.
- `src/agent/prompt.js`, `src/domain/assessment/assessment-workspace.js` →
  require `../application/prompt/prompt-compiler`.
- Other `src/prompts` consumers remain at their current paths during Stage 1;
  they move in Stage 5.
