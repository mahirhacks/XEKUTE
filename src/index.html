Pointer GuideQuick orientation for the local-first pentesting workspace.

      

        
Start with a project
Use Files → Create New Project to create a workspace, or Open Project to open an existing folder. The Target sidebar holds assessment files and custom files.

        
Workspaces
Search finds evidence, Target organizes scope and findings, Security Tools handles request/response work, Toolbox configures recon tools, and Map visualizes application behavior.

        
Chat commands
Type / in Chat to see the three best command matches. Static commands run through the local Python runner; AI commands are expanded into the Agent workflow using their configured aim, prompt, and constraints.

        
Safe and Test modes
Safe keeps Planner, Agent, and Ask human-supervised and blocks sensitive active commands and exploit authority. Test lets Agent run approved sensitive checks while the policy engine, scope, rate limits, approvals, and action log remain in control.

        
Terminal and safety
Use Terminal for local commands and keep testing within the authorization and scope recorded in the assessment. Tool configurations and results stay inside the current project.

        
Useful shortcuts
Ctrl+Shift+F Search · Ctrl+P Quick Open · Ctrl+S Save · Ctrl+` Toggle Terminal · Ctrl+=/Ctrl+- Zoom.
