## Techniques

- Correlate bounded response or timing differences across stable baselines and independent controls.
- Trace values stored in one workflow and consumed by a later query or report.
- Review JSON operators, sort/filter expressions, report builders, search indexes, and GraphQL arguments when observed.
- Separate gateway, ORM, database, and cache behavior with a single-variable differential.
- Demonstrate only the minimum authorized data or boolean effect necessary to establish the claim.

## Verification rules

Advanced classification requires an evidence-backed query path and repeatable control comparison. Never dump data or continue after the security property is demonstrated.
